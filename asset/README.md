# Runtime Assets

- `icon.png`: shared 512px application icon for the header, launch screen, and fallback imagery.
- `favicon.png`: 64px browser tab icon.
- `apple-touch-icon.png`: 180px bookmark icon.
- `home-wordmark.png`: transparent wordmark source.
- `home-wordmark.css`: embedded copy of the alpha mask for HTTP and direct-file previews; horizontal theme gradients and spacing are defined in `style.css`.

Keep only assets referenced by the launcher here. Store retired artwork and working exports outside the repository.
